DviTTS

Zero-shot text-to-speech for English and six Indian languages: Hindi, Marathi, Bengali, Punjabi, Gujarati and Odia.

GitHub code 🤗 DviTTS weights 🤗 DviTTS-Nano weights 🤗 Live demo Android app

DviTTS

0.5B · GPU
  • Zero-shot cloning: reads new text in any voice from 3–10 s of speech and its transcript.
  • Fast: 0.37x real time on an A10G; first audio in 1.5 s (English) and 2.7 s (Hindi).
  • Light on memory: 2.2 GB of GPU memory while speaking.
  • Easy to run: pip install, a command-line tool, and sentence-by-sentence streaming.

Model cardCode

DviTTS-Nano

110M · phone and laptop CPU
  • On-device: 351 MB of ONNX files; no GPU, no PyTorch.
  • Real time on a phone: 0.61x real time and 877 MB peak memory on a Snapdragon 8 Gen 3.
  • 18 preset voices across all seven languages.
  • Ready for apps: an Android library and demo app, plus a Python runner for any CPU.

Model cardCode and app

  • Built for Indian languagesNative scripts in, natural speech out; numbers, dates and money are read the way people say them.
  • One stack, two sizesA 0.5B language model with a flow decoder, and a distilled 110M version with a one-step decoder.
  • WatermarkedEvery clip carries an inaudible AudioSeal mark, so AI-generated speech can be detected.
  • OpenApache 2.0 weights and code.
